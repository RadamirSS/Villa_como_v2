# Архитектурные 2D-планы — отчёт о фактически реализованном

## Исходник и метод

Рабочий дизайн-проект MÈTRE «Вилла на озере Комо», 94 страницы, файл пользователя (09.02.2026 в имени). Чертежи содержат исходную **векторную графику**, поэтому существующие стены и чистовые поверхности мы извлекли из объектов графики PDF без повторной ручной обводки. Для каждого этажа использованы листы **A-14–A-17**: серые заливки конструкций и зелёные линии отделанных поверхностей. Результат — четыре SVG-представления, упакованные gzip в `src/data/source-traces.json` (распаковываются в браузере). Подписи/титульные блоки и другие разделы PDF не копировались.

Для накладываемых цветных зон новых перегородок использованы заливки с **A-10–A-13**: газобетон, ГКЛ, зашивки. Листы соотносятся по одинаковым существующим конструкциям. Координатное совмещение требует дальнейшей метрической проверки; это не автоматически доказанная BIM-сборка.

Номера помещений взяты из координат напечатанных номерных маркеров мебельных планов **A-18–A-21**. Названия и проектные площади перенесены из ведомостей. Точные чистовые размеры проёмов / полотен и ориентации открывания перенесены из дверных спецификаций **A-14–A-17**. Применение этих данных **не делает двери семантически привязанными к стенам** — это отдельная задача.

## Что в точности совпадает с файлом

- Криволинейная форма архитектурного эркера и остальные серые стеновые заливки: извлечены непосредственно из исходных PDF-контуров.
- Линии чистовых поверхностей зелёного цвета на листах A-14–A-17: исходная векторная геометрия.
- Габариты и направления открывания в дверных ведомостях: строки по соответствующим листам.
- Названия и площади помещений, номера на планах: по проектным ведомостям.

## Чего ещё НЕТ и поэтому нельзя считать этап полной точной 2D-CAD моделью

- Все стены не представлены как топологически связанный набор измеренных сегментов с толщинами и уникальными ID.
- Не замкнуты все независимые размерные цепочки в мм, не сопоставлены черновые/чистовые координаты по каждому узлу.
- Нет машинной связи `doorMark → wallId + offsetMm`; визуальная дверь на рабочем листе и спецификация — пока отдельные исходные данные.
- Не реализованы полностью правильные параметры винтовых лестниц, высоты и проёмы перекрытий по общей системе координат.
- Гараж и 3 этаж не привязаны к единой пространственной сетке дома по общим строительным осям.
- Дополнительные 3D-зависимые параметры (фасады, разрезы, кровля, генплан) отсутствуют в исходнике.

**Нельзя объявлять «100% совпадает с проектом» до следующей строгой геометрической проверки.** Текущий результат — проверяемый источник архитектурной 2D-графики с паспортом и всем основным реестром помещений/дверей, пригодный для следующей оцифровки в геометрию, а не исполнительный чертёж.
