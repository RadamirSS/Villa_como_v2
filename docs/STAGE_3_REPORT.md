# Этап 3 — автоматическое построение 3D из 2D (visual prototype)

## Полученный результат

- Собран интерактивный просмотр на Three.js: WebGL, вращение, масштабирование, вид сверху, сброс камеры, адаптивный canvas.
- **368 отдельных полигонов стен** извлечены из реальных серых конструктивных заливок проектных листов A-14–A-17, включая криволинейный эркер первого этажа. Нет ручного назначения положения этих стен.
- Генератор `scripts/build-spatial-model.py` превращает *собственный PDF владельца* в JSON-слой пространственных полигонов (`src/data/spatial-model.json`). Исходный PDF в репозитории отсутствует.
- Полигональные стеновые следы автоматически преобразуются в Three.js Shape/ExtrudeGeometry в браузере. Изменение источника требует повторной генерации JSON.
- Четыре независимых уровня: гараж, первый, второй, третий. Режимы просмотра одного этажа или трёх этажей вместе, собранная / раздвинутая схема.
- Мебель из A-18–A-21 показана **исходной двумерной графикой как проекция на плоскости** (SVG → прозрачная CanvasTexture), а НЕ выдуманной объёмной мебелью.
- Нумерованные маркеры помещений кликабельны и связаны с паспортом помещений из этапов 1–2.
- Весь ранее реализованный режим 2D сохраняется: архитектура, мебель, перегородки, двери, помещения и подробные сантехнические листы.
- Автоматические тесты проверяют происхождение всех стеновых контуров, совпадение PDF viewports, отсутствие выдуманного BIM-статуса и наличие явных ограничений.

## Инженерная суть

Результат — настоящий геометрический 3D-движок **из извлечённых из PDF контуров**, а не статичная 3D-картинка. Но это **визуальный пространственный прототип**, не метрически утверждённый BIM и не полный детальный архитектурный 3D-двойник. Исходник не содержит необходимого для полного автоматического 3D набора семантических стен, деталей проёмов и габаритов мебели. Автоматизация не должна скрывать эти пробелы.

Воспроизводимость:

```bash
pip install -r scripts/requirements-source.txt
python scripts/build-spatial-model.py /path/to/original-METRE.pdf
npm install
npm run check
npm run build
```

В репозитории публикуется только производный слой и его source provenance. Не публикуйте исходный коммерческий PDF без разрешения правообладателя.
