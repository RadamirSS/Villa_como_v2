# Stage 2 → Метрическая BIM-подготовка — открытые требования

- Распознать по A-18–A-21 индивидуальные мебельные объекты, назначить им стабильные ID и параметры \\`xMm/yMm/zMm, widthMm, depthMm, rotation, roomId\\`.
- Сопоставить их с обмерами A-03–A-06 и отделкой A-14–A-17, исключить коллизии, неверные проходы и открывания дверей.
- Для встроенной мебели связать с рабочими развёртками (стенка, перегородка, узел) и отдельно проверить высоты.
- Перенести марки 01–75 со схем A-22–A-29 в единую систему координат; не путать точки водоснабжения и места самих приборов, а также планы и вертикальные развёртки.
- Уточнить марку 54 на A-27: на плане позиция есть, но строка отсутствует в читаемой ведомости.
- Связать каждый сантехнический прибор с ID комнаты, монтажной стеной, высотой и ответственными выводами; не считать одну марку с количеством 2 одной точкой.
- Отладить трансформацию мансарды A-21 относительно A-17 по нескольким независимым размерам.
- Провести инженерную приёмку семантической модели. Только потом разрешать автоматическое 3D.
