# Этап 3 — что осталось для полноценной точной 3D-виллы

1. Утвердить горизонтальный масштаб по двум независимым замкнутым размерным цепочкам каждого уровня. Оцифровать не только серые заливки, но и все тонкие чистовые перегородки; привязать их к осям и габаритам стен.
2. Назначить стабильные ID стенам/узлам; однозначно привязать двери и окна из A-14–A-17, вырезать проёмы с высотой и четвертями. Нельзя превращать 2D-арки открывания в объёмные двери.
3. Получить/восстановить по разрезам высоты, реальные отметки плит, конфигурацию крыши и мансарды. Не выдавать заданные в показе условные 2,65 / 5,90 м за рабочие данные.
4. Восстановить точные внешний контур, террасы, подпорные стены, место гаража, его поворот, рельеф участка по генплану и топосъёмке.
5. Индивидуализировать мебель из A-18–A-21: `ElementPlacement`, стабильные ID, монтажные размеры, известные модели и детальные развёртки; только потом показывать реальные физические 3D-кровати, кухни, диваны, шкафы и т. д.
6. Привязать каждую сантехническую марку A-22–A-29 к 3D-координатам, поверхности и монтажной высоте, отдельно сохранить выводы и изделия. Разобрать спорную №54 на A-27.
7. Материалы, фактуры, освещение, электрика, сценарии и защита локального физического управления — следующими пакетами, не смешивая с неутверждённой архитектурой.
8. CAD/BIM-валидация: геометрические тесты интерференций, независимая проверка площадей помещений, контрольные 2D/3D сечения, экспертная сверка с рабочими листами изамерами на месте.

**Stop condition для заявления «в точности по проекту»:** подтверждены 2D-геометрия в мм, метрики высот, проёмы, и каждая позиция мебели/сантехники. До этого — только визуальный пространственный прототип.
