# Stage 3.6 — exterior correction for the smart-home presentation

## Problem and correction

The previous envelope used the page coordinates of independently placed drawings
as a common building coordinate system. A-15 is translated by −21.24 PDF points
in Y relative to A-04; A-17 is translated by −3.96 X, +6.96 Y relative to A-06.
Those print-layout shifts became real offsets between storeys. The earlier
illustrative exterior traces also introduced notches absent from the source.

The corrected viewer keeps all original 2D data unchanged. It registers the 3D
wall, door, furniture-overlay and room-marker groups to the measurement-plan
frame, and replaces the exterior traces with explicit PDF wall-boundary
coordinates. The trace remains a presentation envelope, not a surveyed BIM.

## Rendering and interaction

- Neutral plaster, stone plinth, recessed glazing and restrained roof palette.
  Final room-specific finishes belong to stage 4.
- Slope-aware site mesh has the lower-floor footprint subtracted; earth is not
  drawn through rooms. The generic grid and cone trees are removed.
- Front, rear/slope, side, overview and top camera views; bounds-aware framing;
  fullscreen presentation and entry to a labelled floor cutaway.
- Static opaque geometry is merged by material. Glass remains separately
  addressable for stage 5; original opening IDs are retained.
- Furniture and plumbing vector archives load on demand.
- If WebGL cannot start, an interactive SVG rendering uses the same Three.js
  meshes and camera. It is labelled as simplified; texture-based furniture
  overlays are disabled in this mode. It is not a substitute for WebGL material
  validation and can show painter-order artifacts in complex overlaps.

## Verification

`npm run build` runs source-data checks, Node geometry regressions, TypeScript
and the Vite production build. Additional regressions exercise actual generated
Three.js meshes: upward roof normals, roof coverage by ray casting, closed
storey bands, finite vertices, aperture bounds, terrain exclusion, draw-call
budget, visibility switches, isolated garage, and planar rooflight panes.

Browser interaction was checked in the provided browser's SVG fallback because
its GPU/WebGL context is disabled. Roof, glazing, terrain and balcony controls,
camera views, fullscreen, room selection, 2D sheets and the independent garage
are covered by UI checks. **Live WebGL shading, shadows and iPhone performance
cannot be certified from that browser.** Offline raster inspection of exported
scene geometry is an additional geometry check, not a screenshot of production.

## Reproduce

```sh
python -m pip install -r scripts/requirements-source.txt
python scripts/build-exterior-concept.py
npm ci
npm run build
```

The source PDF remains private and is not committed. Regeneration of this
explicit exterior trace does not require publishing it.
