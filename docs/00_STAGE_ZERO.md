# Этап 0 — подготовка и границы работ

## Цель
Развернуть независимый v2 с воспроизводимыми сборкой и деплоем, единым контрактом архитектурных данных, ссылками на проектную документацию и нулевой вымышленной геометрией.

## Сделано
- Новый Vite + React + TypeScript frontend, адаптивная подготовительная витрина.
- Состав уровней и проектные площади по A-18–A-21; выделение террасы 22,51 м² внутри общей площади второго этажа.
- Модель типов для будущих стен, проёмов, помещений, предметов мебели и сантехники с обязательным происхождением.
- Единицы данных: целые миллиметры, без смешения координат PDF-пикселей и 3D-метров.
- Автоматические проверки исходных метаданных и запрет неутверждённой геометрии на этапе 0.
- GitHub Actions на push/PR; Vercel строит проект из main с CI-проверками в build-скрипте.
- Реестр источников, ограничений и независимых источников уточнений.

## НЕ входит
- Перенос контуров, стен, дверей и окон.
- Точная 2D или 3D модель, меблирование, сантехника, материалы.
- Реальный контроль света или электрическое проектирование.
- Публикация приватного исходного PDF.

## Non-goals
Не копировать проблемные координаты из v1; не строить красивую условную виллу до проверки размера; не подставлять фасады и генплан, которых нет в PDF.

## Definition of Done
1. Repo содержит структуру, прошедшие данные и код.
2. `npm run build` запускает тесты и TypeScript-проверку.
3. Vercel проект привязан к `RadamirSS/Villa_como_v2`, `main` и успешно публикует подготовительную страницу.
4. Пользователь видит четыре уровня и состояние «не оцифровано».
5. В коде нет объектов с фиктивными стенами и мебели, преподносимых как чертёж.

Наличие Vercel deployment **не означает** приёмку геометрии; в stage 0 её нет.
