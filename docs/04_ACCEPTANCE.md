# Критерии приёмки и QA-гейты

## Stage 0 — платформа
- [x] Публичный репозиторий с новым приложением, без копирования геометрии v1.
- [x] Чёткий контракт координат в мм и источников.
- [x] Данные A-18–A-21 с площадями, количеством помещений и террасой.
- [x] Геометрия = null на всех уровнях и отдельная проверка отсутствия фиктивной геометрии.
- [x] Команда `npm run build` запускает данные, unit tests и TypeScript перед Vite.
- [ ] Vercel Git linkage and READY deployment (фиксируется после фактического подтверждения платформой).
- [ ] Визуальный smoke check deployed UI (фиксируется после фактического теста).

## Stage 1 — CAD-consistent 2D geometry
- Нет самопересечений, открытых контуров и незамкнутых размерных цепочек.
- Контрольные размеры совпадают с рабочими листами, а не с округлёнными пиксельными координатами.
- Все 4 уровня — отдельные проверяемые datasets, прогресс поэтажный.
- Каждая стена/проём с ID, типом, источником, статусом проверки.
- Специализированные допуски только после определения точности PDF/замеров; нулевой допуск обещать нельзя.
- Визуальные overlays рабочих листов и автоматический отчёт отклонений.
- Обязательное утверждение 2D перед меблированием и 3D.

## Stage 2 — interior placement
- Поштучный перечень объектов, размеры и расположение; объекты проверены по A-18–A-29 и развёрткам.
- Нет коллизий с дверями/проходами. Сантехника имеет корректные монтажные привязки.

## Stage 3+ — 3D, finish, lighting
- 3D строится из той же геометрии; совпадают ID и координаты 2D/3D.
- Для отсутствующих фасадов/разрезов/кровли сохраняются флаги неопределённости.
- Светильники и физические группы не выводятся из названий «сцен» без электрической схемы.
- Smoke test: desktop/mobile, zoom/orbit, floor isolation, 2D↔3D correspondence, color/material, regression screenshots.

## Отчёт проверки
На каждый пакет: commit/PR, изменённые файлы, листы источника, список неподтверждённых размеров, результат тестов, ссылка preview Vercel. Без «100%» на основании визуальной похожести.
