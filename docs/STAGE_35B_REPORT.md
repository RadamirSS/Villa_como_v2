# Этап 3.5 — пакет Б: визуальный внешний облик виллы

## Что реализовано

- **Настоящая объёмная 3D-оболочка**, состоящая из фасадных стеновых панелей с отверстиями под декоративное остекление, а не только интерьерных стен из этапа 3.
- **Четыре привязанных к источникам контура**: гараж A-14, первый этаж A-15, второй A-16, мансарда A-17. Контуры воспроизведены по *видимым внешним границам* стен на планах (расшифровка точек хранится в генераторе) с сохранением эркера и уступов. Это визуальная трассировка, **не сертифицированная геометрия экстерьера**.
- **41 концептуальная фасадная оконная позиция**, размещённая по внешнему плану. Материалы стекла и рам, высоты/ширины окон и архитектурная композиция — допущения, так как нет полных фасадных листов. Их можно отключить отдельным переключателем.
- **Крыша для собранного дома**: два демонстрационных скатных объёма над мансардой + несколько низких покрытий над частями второго уровня. Фальцевый рисунок и свесы — дизайнерская концепция, никакой «точной проектной кровли» из предоставленного PDF вывести нельзя.
- **Терраса второго этажа** по помещению №13 A-20 с плоским настилом и прозрачным ограждением. Площадь 22,51 м² — из ведомости; упрощённый полигон для 3D имеет свою **другую, непроверенную** площадь. Статус не маскируется.
- **Гараж отдельным видом**: наружные стены, условная плоская крыша, вспомогательный объём из A-14, визуальная рольставня. Реальных габаритов гаражного въезда и точной геопривязки гаража в PDF нет. Не используется выдуманная посадка гаража справа от дома.
- **Три режима интерфейса**: «Готовый дом» (собранные фасады и крыша), «Без оболочки» (исходные 3D-стены с разрезом по этажам) и «Исходные стены». Крыша, остекление и терраса переключаются отдельно. Режимы 2D и 3D, мебель, сантехнические планы, паспорта 44 помещений и контрольные размеры не удалены.
- **Природный фон** ограничен декоративной землёй и деревьями, без придуманной топографии озера, точных подпорных стен, заезда и посадки гаража.

## Воспроизводимость и контроль

```bash
python scripts/build-exterior-concept.py
npm run check:exterior
npm run check
npm run build
```

- Генератор: `scripts/build-exterior-concept.py`.
- Структурированные данные: `src/data/exterior-concept.json`.
- 3D-компонент: `src/components/ExteriorConcept.ts` и интеграция в `src/components/Villa3D.tsx`.
- Ограничения проверяются `scripts/verify-exterior.mjs` и `tests/exterior.test.mjs`.
- Векторные данные 2D сохранены, исходный 94-страничный PDF не публикуется.

## Критерий приёмки для демонстрационного пакета Б

1. При загрузке страницы пользователь видит **собранную объёмную виллу с крышей, оконными рамами и остеклением**, а не только перегородки без перекрытия.
2. Вращение и приближение камеры работают, вилла не обрезана; верхние кровельные поверхности действительно выглядят наклонными.
3. Отключение «Крыша», «Остекление» и «Терраса» изменяет сцену; режим «Без оболочки» возвращает исходные стеновые контуры.
4. Все четыре этажа доступны; гараж показывается отдельным строением без фиктивного присоединения к вилле.
5. Отчёт и экран **явно предупреждают** о концептуальных кровле, высотах, фасадах и остеклении.

**Блокируется утверждение «в точности по архитектурному проекту»:** нет проектного плана кровли, наружных фасадов, основных разрезов и генплана. Пакет Б завершает демонстрационный *облик*, не исполнительные чертежи дома.
