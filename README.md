# Villa Como v2 — точная цифровая модель виллы

Новый проект поэтапного восстановления **2D → 3D → интерьер → инженерные системы** по рабочей документации MÈTRE «Вилла на озере Комо» (PDF, 94 страницы, версия файла 09.02.2026).

> **Текущий статус: этап 0 / подготовка.** Геометрия намеренно НЕ создана. Ни визуальный интерфейс, ни записанные площади не означают, что обмерные планы уже перенесены.

## Принципы

1. **Единый источник геометрии** для 2D, 3D, проёмов, мебели, сантехники и света. Никаких независимых координат 2D/3D.
2. Все инженерные координаты в **целых миллиметрах**, все размеры с источником (лист и статус проверки). Визуализация конвертирует мм → м только на границе рендера.
3. Проектные данные, уточнения владельца и условные предположения хранятся **раздельно**.
4. Сначала контролируемый контур и реальные размерные цепочки, затем стены, проёмы, двери, лестницы, затем мебель, сантехника, 3D, отделка и освещение.
5. Неподтверждённая геометрия не получает статус «точная». Отсутствующие фасады, разрезы, кровля и топография не подменяются фантазией.
6. Реализация v1 **не копируется**: там ручная обводка плана и визуально упрощённые интерьеры. Из v1 позже можно переносить только проверенные UX-решения.

## Установка

```bash
npm install
npm run dev
npm run check
npm run build
```

- `npm run dev`: локальная подготовительная витрина
- `npm run check`: тесты реестра + проверка TypeScript
- `npm run build`: проверки + production-сборка в `dist/`
- Vercel: Vite, корень репозитория, production branch `main`.
