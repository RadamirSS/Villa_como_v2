## Этап 1: source-faithful 2D plans

Независимая реализация архитектурного 2D-просмотра по исходному PDF MÈTRE (94 страницы). Вместо ручной геометрии из `v1` — непосредственно извлечённые векторные заливки и линии чистовых стен с листов A-14–A-17. Новые перегородки накладываются с A-10–A-13; номера помещений автоматически сопоставлены с напечатанными маркерами A-18–A-21, а спецификации дверей вручную сверены с соответствующими ведомостями. 4 уровня, 44 позиции помещений, 33 позиции внутренних дверей с учётом трёх одинаковых дверей в гараже.

### Важно: граница точности

**Скопированы линии источника, а не построена завершённая BIM-модель в миллиметрах.** Данные статуса `draft`; канонический `FloorGeometry` остаётся `null` до метрической валидации. Точные проектные площади и размеры из ведомостей показаны отдельно, не вычислены из отображаемой SVG-графики. SVG сохраняет исходные PDF-кривые; новые перегородки совмещены по существующим конструктивным линиям, но требуется полный размерный аудит перед использованием в строительстве или генерацией 3D.

Отсутствуют фасады, общие разрезы, план кровли, генплан и топосъёмка — их нельзя воспроизвести с гарантией 100% соответствия только по предоставленному PDF. Исходный 94-страничный PDF не публикуется в GitHub/Vercel, добавлены только необходимые векторные производные архитектурных листов без титульных блоков и фото.

### Возможности

- 4 независимых плана с масштабированием колесом/кнопками, панорамированием мышью и касанием;
- включение/скрытие чистовых граней, новых перегородок и номеров помещений;
- выбор 44 помещений на плане, чтение проектной площади из ведомости;
- таблица дверей с марками, размерами монтажного/чистового проёма, дверного полотна и направлением открывания;
- контрольные числовые размеры по листам;
- скачивание исходного SVG слоя для каждого этажа;
- автоматические тесты наличия слоёв, схемы и итоговых площадей.

### Установка и проверки

```bash
npm install
npm run check
npm run dev

```

Проверяемость данных описана в [`docs/STAGE_1_REPORT.md`](docs/STAGE_1_REPORT.md). Извлечение SVG повторяемо из пользовательского PDF, но сам исходник не хранится в публичном репозитории. Будущий полноценный геометрический CAD/BIM экспорт требует закрытия задач [`docs/STAGE_1_REMAINING.md`](docs/STAGE_1_REMAINING.md).

## Этап 3 — пространственная 3D-визуализация

В главном приложении доступно переключение **3D модель / 2D чертёж**. Реальная трёхмерная сцена строится автоматически из пространственных контуров серых конструктивных стен на A-14–A-17 и поддерживает вращение, приближение, вид сверху, скрытие стен, выбор этажей и просмотр раздвинутой сборки. Мебельный слой A-18–A-21 пока отображается точно по 2D как проекция на пол, не как объёмные редактируемые объекты.

- [Технический отчёт Stage 3](docs/STAGE_3_REPORT.md)
- [Недостающая работа перед BIM-точностью](docs/STAGE_3_REMAINING.md)
- `python scripts/build-spatial-model.py <owner-source.pdf>` — воспроизводимая генерация стеновых следов из частного PDF в `src/data/spatial-model.json`. Не коммитить PDF.
- `npm run check:spatial` — проверки источников и согласованности данных трёхмерной сцены.

**Важно:** высоты, масштаб, платформы и положение гаража не являются сертифицированными размерами. Точный замкнутый конструктив / крышу / окна / 3D-мебель нельзя достоверно получить только из данного неполного набора сведений.

## Этап 3.5 — пакет А: геометрия стен и дверей (source-trace, **не закрытая BIM-модель**)

Проверены восемь независимых векторных размерных линий по A-03/A-05/A-06/A-15/A-16. Каждый из 368 стеновых полигонов получил стабильный ID. **Все 33** нанесённые в PDF дверные позиции имеют источниковые отрезки 2D полотен и размеры по ведомостям. В 3D настраивается показ источниковых полотен; 18 из 33 дверных осей удалось сопоставить с настоящими разрывами стеновой заливки. Остальные 15 по этой проверке **неразрешены**. Масштаб 3D-просмотра ориентировочный, на отдельных опорных линиях расхождение до 1,493%.

- [Техническая проверка пакета А](docs/STAGE_35A_REPORT.md)
- [Открытые инженерные вопросы](docs/STAGE_35A_REMAINING.md)
- `npm run check:geometry` проверяет метаданные, стеновые ID и все 33 источниковые двери.
- `python scripts/build-architectural-geometry.py /private/source.pdf` заново строит данные по исходному PDF (требуется локально установленный PyMuPDF/numpy/opencv-python).

**Не утверждены** полные оконные 3D-проёмы, ступени и отверстия лестниц, реальная геометрия плит, фасады/кровля и высоты мансарды. Исходное изображение не равно конструктивной документации. Эти вопросы остаются открытыми; называть весь пакет А «в точности по проекту» нельзя.
