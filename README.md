# Villa Como v2 — архитектурные 2D-планы

**Live:** https://villa-como-v2.vercel.app/

## Этап 1: source-faithful 2D plans

Независимая реализация архитектурного 2D-просмотра по исходному PDF MÈTRE (94 страницы). Вместо ручной геометрии из `v1` — непосредственно извлечённые векторные заливки и линии чистовых стен с листов A-14–A-17. Новые перегородки накладываются с A-10–A-13; номера помещений автоматически сопоставлены с напечатанными маркерами A-18–A-21, а спецификации дверей вручную сверены с соответствующими ведомостями. 4 уровня, 44 позиции помещений, 33 позиции внутренних дверей с учётом трёх одинаковых дверей в гараже.

### Важно: граница точности

**Скопированы линии источника, а не построена завершённая BIM-модель в миллиметрах.** Данные статуса `draft`; канонический `FloorGeometry` остаётся `null` до метрической валидации. Точные проектные площади и размеры из ведомостей показаны отдельно, не вычислены из отображаемой SVG-графики. SVG сохраняет исходные PDF-кривые; новые перегородки совмещены по существующим конструктивным линиям, но требуется полный размерный аудит перед использованием в строительстве или генерацией 3D.

Отсутствуют фасады, общие разрезы, план кровли, генплан и топосъёмка — их нельзя воспроизвести с гарантией 100% соответствия только по предоставленному PDF. Исходный 94-страничный PDF не публикуется в GitHub/Vercel, добавлены только необходимые векторные производные архитектурных листов без титульных блоков и фото.

### Возможности

- 4 независимых плана с масштабированием колесом/кнопками, панорамированием мышью и касанием;
- включение/скрытие чистовых граней, новых перегородок и номеров помещений;
- выбор 44 помещений на плане, чтение проектной площади из ведомости;
- таблица дверей с марками, размерами монтажного/чистового проёма, дверного полотна и направлением открывания;
- контрольные числовые размеры по листам;
- скачивание исходного SVG слоя для каждого этажа;
- автоматические тесты наличия слоёв, схемы и итоговых площадей.

### Установка и проверки

```bash
npm install
npm run check
npm run dev
npm run build
```

Проверяемость данных описана в [`docs/STAGE_1_REPORT.md`](docs/STAGE_1_REPORT.md). Извлечение SVG повторяемо из пользовательского PDF, но сам исходник не хранится в публичном репозитории. Будущий полноценный геометрический CAD/BIM экспорт требует закрытия задач [`docs/STAGE_1_REMAINING.md`](docs/STAGE_1_REMAINING.md).
